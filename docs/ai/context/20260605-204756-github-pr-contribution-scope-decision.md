# GitHub 热门项目贡献范围决策

## 已确认决策

首版只寻找低风险但有实际价值的贡献切入口：

- 文档缺口修复。
- 示例补全。
- 测试补充。
- 小 bug 修复。
- CI、类型错误或静态检查错误修复。

## 排除范围

- 纯格式化 PR。
- 批量拼写修正。
- 无 issue 背景或无维护者信号的大规模重构。
- 与项目方向无关的“蹭热度”变更。

## 设计影响

- 机会分析器要优先读取 README、CONTRIBUTING、issue、PR 模板、测试配置和 CI 状态。
- 候选 PR 必须附带价值说明、验证结果和风险说明。
- 每日目标是至少 5 个“可人工确认提交”的候选 PR，而不是保证机械提交 5 个 PR。
