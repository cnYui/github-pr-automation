# 热门项目报告语言范围变更

## 用户反馈

当前页面只有 1 个项目，数量太少。用户希望从 GitHub 热门排行榜拉取更多项目，并且不再限制 TypeScript 或 Python，其他语言也可以。

## 已确认变更

- 报告页面继续保持只读表格。
- 数据来源改为 GitHub Trending daily 的当前热门项目。
- 展示语言范围放宽为任意语言。
- 首次填充目标为前 10 个左右热门项目。

## 设计影响

- `primaryLanguage` 不能再是 TypeScript、JavaScript、Python 枚举，应放宽为非空字符串。
- 页面渲染逻辑无需变化。
- PR 切入口和风险仍然只做展示，不触发 fork、提交或开 PR。
- 对非熟悉语言项目，推荐动作应偏保守，优先建议文档、示例、测试入口。
