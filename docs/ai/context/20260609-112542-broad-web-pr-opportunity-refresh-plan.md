# 全网 PR 机会刷新计划

## 目标

- 从 GitHub、Reddit 和社区搜索中寻找当前受关注项目或明确用户需求。
- 最终只把可落到具体仓库、具体 open issue、且适合小范围贡献的候选写入页面数据。
- 不修改源码、页面结构或样式，只刷新报告 JSON 和新增上下文记录。

## 筛选口径

- 必须能定位到 GitHub 仓库和明确问题来源。
- 优先选择仍 open、需求清楚、范围小、可测试的 issue。
- 必须检查是否已有重复 open PR；存在重复 PR 的方向不列为 `值得继续`。
- Reddit 或社区帖子只作为发现线索，不能单独作为可推进依据；需要回到 GitHub issue 或仓库事实核验。

## 落地范围

- 更新 `public/reports/latest.json`，供开发页读取。
- 同步更新 `dist/reports/latest.json`，保持静态构建产物可直接展示新报告。
- 新增一份 `docs/ai/context/` 复盘文档，记录来源、入选候选、排除项和风险。

## 验证

- 使用现有 schema 校验报告 JSON。
- 运行不触碰源码的项目测试或至少运行报告 schema 相关测试。
- 检查 `git diff --check`，避免数据文件存在格式问题。
