# 本地页面无法打开调试记录

## 现象

用户在应用内浏览器打开 `http://127.0.0.1:5174/` 时页面无法访问。

## 根因

- `127.0.0.1:5174` 没有进程监听。
- 昨天的 Vite dev server 已退出。
- `5173` 被其他项目占用，因此本项目需要继续使用 `5174`。

## 处理

- 重新启动本项目 dev server：
  - `npm run dev -- --host 127.0.0.1 --port 5174`
- HTTP 验证：
  - `/` 返回 200。
  - `/reports/latest.json` 返回 200。
- 应用内浏览器验证：
  - 页面标题为 `GitHub PR 机会日报`。
  - 表格行数为 1。
  - 按钮数量为 0。

## 当前可用地址

`http://127.0.0.1:5174/`
