## 步骤

1. 确认上游状态
   - 运行 `git status --short --branch`
   - 创建分支 `codex/fix-interceptor-new-document`
   - 安装依赖：`npm install`

2. 写失败测试
   - 在 `src/browser/base-page.test.ts` 的 `ActionPage` 测试附近新增 `BasePage installInterceptor` 测试组。
   - 测试一：带 `cdp` 的 page 调用 `installInterceptor('batchSearch')` 后，应调用 `Page.addScriptToEvaluateOnNewDocument`。
   - 测试二：`cdp` 抛错时，`installInterceptor()` 仍 resolve，且当前 document 的 `evaluate()` 仍执行。
   - 运行 `npx vitest run --project unit src/browser/base-page.test.ts`，预期新增测试失败。

3. 实现最小修复
   - 在 `BasePage.installInterceptor()` 中保存 `generateInterceptorJs(...)` 返回值。
   - 先执行原有 `evaluate(interceptorJs)`。
   - 再尝试调用可选 `cdp('Page.addScriptToEvaluateOnNewDocument', { source: '(' + interceptorJs + ')()' })`。
   - 捕获 CDP 失败，保持现有 evaluate 路径可用。

4. 验证
   - 运行 `npx vitest run --project unit src/browser/base-page.test.ts`。
   - 运行 `npx tsc --noEmit`。
   - 检查 `git diff`，确保只包含测试和实现。

5. 提交和 PR
   - commit：`fix(browser): persist interceptor across navigation`
   - push 到用户 fork 的分支。
   - 创建 PR 到 `jackwener/OpenCLI:main`，正文说明：
     - 避免重复 #1851/#1854。
     - 关联 #584。
     - 修复范围是 `installInterceptor()` 对后续 document 的注入。
     - 列出本地验证命令和结果。
