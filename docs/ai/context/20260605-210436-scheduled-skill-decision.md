# 定时任务作为 Skill 的设计决策

## 已确认决策

用户希望把每日 GitHub 热门项目发现和 PR 切入口分析任务写成一个 Codex Skill。

## Skill 定位

该 Skill 应指导 Codex 执行每日贡献机会扫描：

- 拉取高热度候选仓库。
- 计算或估算 24 小时新增 Star。
- 分析 JS/TS 与 Python 项目的低风险贡献切入口。
- 输出只读报告数据。
- 生成单页表格可展示的数据结构。

## 明确边界

- Skill 不应鼓励无人值守提交 PR。
- Skill 不应把“每天至少 5 个 PR”解释为机械提交数量。
- Skill 的目标是产出可审阅的高质量候选项。
- 后续若真正创建 Skill，需要按 Skill 创建规范保持 `SKILL.md` 简洁，并通过场景验证它不会诱导低质量批量 PR。
