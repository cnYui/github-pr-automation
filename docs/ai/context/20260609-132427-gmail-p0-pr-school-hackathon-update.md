# Gmail 巡检 P0 优先级调整记录

## 背景

用户要求将 PR、学校以及黑客松相关邮件提升为 P0，其他分类保持不变。

## 调整内容

已更新 Codex automation `gmail`：

- `GitHub/PR/CI 需要动作` 保持 P0。
- 新增 `P0 学校/校园事务`：福井大学、学务、国际课、课程、校园活动、附件通知、学校手续、学校截止日期。
- 新增 `P0 黑客松/开发比赛机会`：Devpost、Hugging Face、hackathon、开发者竞赛、报名、credit、截止日期、获奖通知。
- 原 `P1 学校/合同/生活行政` 拆分为：
  - 学校相关进入 P0。
  - Sun-Net、PayPay、合同到期、账单、申请未完成等非学校生活行政保留 P1。
- 原 `P2 活动/机会` 保留普通活动、webinar 和 AI/开发相关活动；黑客松相关按 P0 处理。

## 边界

巡检仍保持只读：不发送邮件、不删除/归档、不标记已读、不打开附件、不点击外链。
