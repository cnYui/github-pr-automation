# 系统拆分决策

## 已确认决策

首版拆成 4 个部分：

| 部分 | 职责 |
| --- | --- |
| `github-daily-pr-opportunity-scan` Skill | 规定每日扫描流程、质量门槛、风险评级和输出格式 |
| 扫描脚本 | 调 GitHub API，保存 Star 快照，分析仓库，生成报告 JSON |
| 单页报告 | 读取 JSON，渲染只读表格，不含按钮 |
| 后续推进流程 | 用户在对话中点名某个项目后，再单独 clone、分析、改代码、跑测试、准备候选 PR |

## 关键边界

- 报告页只帮助判断哪个项目值得继续。
- 报告页不操作 GitHub。
- 真正改代码和准备 PR 是下一步独立任务。
- 后续推进必须继续遵守人工确认和质量门槛。
