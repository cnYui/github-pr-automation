# GitHub 热门项目首版技术栈范围决策

## 已确认决策

首版只覆盖以下技术栈仓库：

- TypeScript / JavaScript。
- Python。

## 选择原因

- 两类生态的测试、lint、类型检查、文档与示例结构更容易自动识别和验证。
- 对低风险贡献类型更友好，例如测试补充、示例补全、类型错误修复、小 bug 修复。
- 限制技术栈能降低误判和低质量 PR 风险。

## 设计影响

- 候选仓库筛选阶段需要识别主语言和项目结构。
- 机会分析器首版只实现 JS/TS 与 Python 的规则。
- 其他语言仓库即使热度高，也进入“暂不处理/后续扩展”列表。
