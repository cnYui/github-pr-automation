# 每日 PR 机会流水线自动化实施计划

## 1. 基线核验

- 确认流水线当前无未完成运行。
- 运行全量测试和 TypeScript 类型检查。
- 核对 Codex 固定本地项目 ID 和现有自动化，避免重复或误改反馈监控任务。

## 2. 创建定时任务

- 新建独立 cron 自动化，绑定主控仓库本地项目。
- 设置每天日本时间 09:00 运行。
- 提示词只调用完整流水线 Skill，并明确恢复、扫描、preflight、实现、验证、发布、关闭窗口和禁止自动 merge 的要求。

## 3. 验证与记录

- 读取新自动化配置，确认名称、状态、项目、频率、模型和提示词。
- 新增实施记录，保存自动化 ID、调度和边界。
- 在 `AGENTS.md` 追加项目记忆，不修改历史上下文文件。

## 4. 后续加固

- 修复扫描 CLI 参数和帮助行为。
- 增加 GitHub API 超时、重试和 rate-limit 退避。
- 增加 lease heartbeat 与跨阶段一致性校验。
- 处理报告不可变批次和 `dist/reports` 同步问题。
