## 硬门槛

- 排除 archived、明显停滞或 issue 已在 main 修复的仓库。
- 排除已有同向 open PR、已被认领且正在实现的方向。
- 排除必须依赖云账号、企业服务、集群、多节点或重型模型下载才能验证的实现。
- 大仓库只保留文档、示例、坏链、配置说明等低风险切口。
- 若维护者要求 issue-first 或外部贡献者预审批，降级为 `谨慎` 或 `跳过`。

## 排名规则

- `值得继续`：切口明确且小、无明显重复 PR、本地验证路径清晰、基础设施依赖轻。
- `谨慎`：方向有价值，但仍需复现、维护者确认，或验证成本偏高。
- `跳过`：重复、不可验证、范围过大、维护门槛不匹配或投入产出比低。
