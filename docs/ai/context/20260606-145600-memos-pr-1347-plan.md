# MemOS PR #1347 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 `memos-local-openclaw` 自动召回增加可配置短查询过滤阈值，避免短确认词触发记忆注入。

**Architecture:** 在现有 `recall` 配置块内增加 `autoRecallMinQueryLength`。自动召回 hook 在进入本地/Hub 搜索前读取已解析配置并做一次长度判断，手动 `memory_search` 不受影响。

**Tech Stack:** TypeScript, Vitest, MemOS `apps/memos-local-openclaw`, mirrored `packages/memos-core`.

- [ ] **Step 3: Use resolved threshold in hook**

Replace the hardcoded check:

```ts
if (query.length < 2) {
  ctx.log.debug("auto-recall: extracted query too short, skipping");
  return;
}
```

with:

```ts
const autoRecallMinQueryLength = ctx.config.recall?.autoRecallMinQueryLength ?? DEFAULTS.autoRecallMinQueryLength;
if (query.length < autoRecallMinQueryLength) {
  ctx.log.debug(`auto-recall: extracted query shorter than autoRecallMinQueryLength=${autoRecallMinQueryLength}, skipping`);
  return;
}
```
